Application stack

Framework, languages & tools

Python microframework · server-rendered pages and JSON APIs

Languages & interface

Backend & operations

  • Data: Flask-SQLAlchemy ORM; SQLite for local setup; MySQL supported with PyMySQL.
  • Identity & protection: Flask-Login, Werkzeug password hashing, Flask-WTF CSRF protection, Flask-Limiter rate limits.
  • Deployment: Waitress WSGI server; Redis can provide shared production rate-limit storage.
  • Testing: Python unittest test suite.

Roadmap delivery

Capabilities and remaining setup

Implemented workflows and deployment prerequisites; this is not a complete security audit.

01

Parent-to-student links · implemented

Administrators manage links in User Management. Parents see linked attendance and exam records; fee information remains restricted.

02

News publishing · implemented

Administrators can save drafts, publish, unpublish, edit, and delete announcements in News Management.

03

Class management · implemented

Classes are stored as grade-and-section records and linked to students. Existing student groups are migrated during database initialization.

04

Student sign-up verification · strengthened

Student ID and date of birth are checked, then an administrator must approve access. This is manual school verification, not government-ID or third-party identity proof.

05

Configurable batches · implemented

Administrators can manage registration batch choices in Settings; existing account batch values are preserved.

06

Demo credentials · development only

The requested demo account remains restricted to localhost development. Production initialization requires a strong administrator password.

07

Recovery & multi-factor sign-in · implemented

Time-limited verified-email password reset and authenticator-app MFA are available. Configure SMTP with TLS/SSL before enabling email delivery in a deployment.
